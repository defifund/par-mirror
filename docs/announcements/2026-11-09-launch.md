## 二、公告正文（长图里的文字）

### par 社区镜像上线了：par.defi.club

par.family 下线后，我们用 par 开源的合约和 SDK 重建了一个社区镜像，读取的仍是链上同一套合约。原来发过的币、成交记录和持仓都还在，又可以看、可以用了。

支持的链：Robinhood Chain · Base · Arc

### 现在能做什么

- **浏览代币**：三条链上所有 par 代币，按热度、市值、新币、成交量排序，支持搜索
- **代币页**：K 线、成交、持有人、历史分红、销毁、Floor 价格墙，有新成交自动刷新
- **发币**：单交易对或多市场（最多 5 个），可直接选代币化股票作交易对
- **组合 · 领取**：查看各链持仓，领取作为创作者应得的手续费
- **统计**：成交量、手续费去向、分红、排行榜，7 天 / 30 天 / 90 天 / 全部
- **个人资料**：钱包签名登录（免费、不发交易），给地址起名字；发币人可修改代币介绍
- **原站资料都保住了**：约 2,950 个代币图片已转存到镜像自己的 IPFS 节点并备份，不会因 Pinata 停服丢失；原来的 /t/ 短链接照常可用

### 需要知道的几点

- **不是原团队运营。** 镜像没有任何管理员权限、不收协议费；所有交易从你自己的钱包发出，由你自己确认。
- **原团队负责的功能已停：** 持有人分红、回购销毁、X / GitHub 账号认领。新发币暂时只开放"手续费归创作者"模式。
- Arc 的历史数据还在补，较早的记录会陆续出现。
- **合约未经审计，交易功能请先小额试用。** 遇到问题欢迎直接反馈。

定位：一切以团队为主，我们是配合和备份。建议通过私信或官方邮箱发，不要发在公开群里；在社区公告之前或同时发出。如果通过 API 发到 X，按规则要去掉网址。

### English

Hi par team,

Since par.family went offline, a few of us in the community put up a mirror at par.defi.club so holders and creators could keep seeing their tokens and using the contracts. I wanted you to hear it from us first.

To be clear about where we stand: the team leads, we follow. This is meant as support and a backup, nothing more.

- It is rebuilt only from your open-source contracts and SDK, and reads the same on-chain contracts (Robinhood Chain, Base, Arc).
- It holds no admin keys, takes no fees, and every transaction is signed in the user's own wallet. The site says plainly that it is a community mirror, not run by the team.
- Launches made through it carry a marker in the salt, so they can always be told apart.
- What only the team can do is shown as paused, not replaced: holder payouts, the buyback/burn vault, X/GitHub claims. New launches are limited to "fees to creator".
- We kept a copy of the original token images (about 2,950, pinned on our own IPFS node with a backup), and the old /t/ short links still resolve. Happy to hand any of this over.

If you'd like anything changed (the name, the wording, a link to your official channels) or would prefer we take it down or redirect to you once you're back, just say so and we'll do it.

Thank you for building par.
